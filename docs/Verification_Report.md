## التغطية

تشمل المصادقة والتحقق من المدخلات والصلاحيات والبريد الفريد، حساب الترتيب وتصحيح النتائج وسجلها، تنفيذ استعلام الهدافين على مزود علائقي، تاريخ العضويات وتثبيت القائمة، تعارض المواعيد، سعة الملعب والعروض، ذرية الحجز وثبات السعر وIdempotency، ملكية الحجز، الإلغاء وموعد منعه، رفض التذكرة الملغاة والدخول المتكرر، ورفض تحديث مخزون بنسخة قديمة وقيود السعة والنتيجة على مستوى القاعدة.

## حدود القبول

اختبارات SQLite لا تثبت سلوك الأقفال وCollation وDeadlocks في SQL Server؛ لذلك يُشغَّل `scripts/test-concurrency.ps1` على SQL Server. التحقق تم على LocalDB وليس على خادم الفريق. العمليات الأخرى التي تستخدم Serializable (الجدولة، إنشاء العروض، فحص الدخول) لم تختبر بحمل متزامن؛ عند deadlock ترجع 409 `transaction_conflict` بدل 500. لم تنفذ اختبارات حمل أو نشر Production، ولم يشغل GitHub Actions في حساب فعلي.
